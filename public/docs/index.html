O que é o Axolotl BR

O Axolotl BR é uma comunidade brasileira de quem gosta de jogar, criar e programar. Começou em 2020 como um grupo de amigos no Discord e virou um ecossistema: servidor de Discord, o Axolotl SMP de Minecraft, o ALT Bot, o design system Prism e projetos de código aberto.

Sem empresa por trás e sem fórmula pronta. Sua comunidade na internet, de player para player. A ideia cabe em três palavras: jogar, criar, conectar.

Linha do tempo

  • 2020 · um grupo de amigos monta um servidor no Discord. Sem plano, sem nome chique.
  • 2021 – 2022 · campeonatinhos internos, testes de servidor e os primeiros traços da identidade.
  • 2023 – 2024 · bot próprio, ideias de jogo e os primeiros rascunhos do SMP.
  • 2025 · site, bots e labs saindo do papel.
  • 2026 · uma nova casa, identidade definida e vários projetos ganhando forma.

Nossos valores

  • Gente antes de número. Não queremos ser a maior comunidade da internet, queremos ser uma que vale a pena encontrar.
  • Feito de verdade. Nada de número, status ou recurso inventado. O que é demo diz que é demo.
  • Aberto. Código em público na org do GitHub. Qualquer um pode olhar, aprender e contribuir.
  • Todo mundo participa. Não precisa ser alguém importante pra criar, compartilhar e fazer parte.

Como entrar

  1. Entra no Discord pelo convite oficial. É de graça e não precisa de convite especial.
  2. Lê as regras. São seis, curtas.
  3. Manda um oi. O ALT tá lá e você já começa a ganhar XP conversando.
  4. Usa >ajuda pra ver o que o bot faz e >server pra conhecer o servidor.

Os links oficiais ficam em /redes. O que não está lá não é a gente.

Regras e diretrizes

O resto é bom senso. Isso aqui é o inegociável:

  1. Sem ódio nem preconceito. Ataque a quem a pessoa é cai de verdade.
  2. Sem spam nem flood. Inclui divulgação sem permissão.
  3. Sem golpe nem pirataria. Tolerância zero.
  4. Conteúdo +18 só no lugar certo. Fora do canal marcado, é ban.
  5. Respeita a moderação. Discordou? Chama no privado.
  6. No jogo, joga limpo. Sem hack, x-ray ou grief.

A escada é aviso → mute → ban, salvo caso grave. Viu algo errado: tira print e chama um moderador no privado. Tudo em detalhe nas regras completas.

Como participar dos projetos

Todo projeto aberto está no GitHub e no showcase. Dá pra ajudar de vários jeitos, não só com código:

  • Ideia ou bug: abre uma issue no repositório do projeto, ou um ticket de bug no Discord.
  • Código: pega uma issue, faz um fork e manda um pull request (veja abaixo).
  • Arte, vídeo, mapa: posta no Discord. Projeto da comunidade tem palco no site. Usa o kit de mídia.
  • Evento: propõe no Discord. O que for marcado aparece em /eventos.

Rodando os projetos

Site (React + TypeScript + Vite)

git clone https://github.com/Axolotl-BR/Axolotl-BR
cd Axolotl-BR
npm install
npm run dev        # desenvolvimento
npm run typecheck  # checagem de tipos
npm start          # build + servidor de produção

A camada visual é o Prism. Usa os tokens e componentes dele antes de criar estilo novo.

ALT Bot (Python + discord.py)

git clone https://github.com/OFabiano1/ALT-BOT
cd ALT-BOT
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env   # preenche o TOKEN no mínimo
python main.py
python -m pytest         # testes

No developer portal do Discord, liga os intents members e message_content. Usa um bot de teste seu, nunca o token oficial.

Convenções

  • Commit: x.y.z - o que mudou, tudo minúsculo, versão em sequência. Ex.: 0.5.3 - página de eventos.
  • Segredo nunca vai pro git. Token e chave ficam em variável de ambiente; o repositório só tem o .env.example.
  • Nada inventado. Número, status e atividade só entram se vierem de uma checagem real.
  • Mudança pequena e focada. Um PR resolve uma coisa.
  • Acessível e responsivo. Funciona no celular, no teclado e com leitor de tela.

Seu primeiro pull request

  1. Faz um fork do repositório e cria uma branch: git checkout -b minha-mudanca.
  2. Faz a mudança e roda as checagens do projeto (typecheck, testes).
  3. Commita no formato da casa e dá push na sua branch.
  4. Abre o PR explicando o que mudou e por quê. Print ajuda se mexeu em tela.
  5. Responde a revisão. Depois do merge, seu nome vai pro histórico do projeto.

Travou? Pergunta no Discord. Ninguém nasceu sabendo.

Axolotl Lab

A central interna de desenvolvimento do Axolotl BR: projetos, tarefas, infraestrutura e equipe num lugar só. O Lab não hospeda código (isso fica no GitHub); ele organiza o que está em volta.

  • Quem acessa: só a equipe. Não existe cadastro aberto; a entrada é por convite (Lab Access), com login por e-mail ou Discord.
  • O que tem: Command Center com serviços no ar e incidentes, projetos com página própria, tarefas, membros e papéis.
  • Stack: React + Vite + TypeScript no front, FastAPI (Python) e SQLite no back.
  • Código: repositório privado.

Quer entrar pra equipe? Mostra serviço nos projetos abertos e chama no Discord.
