# ROADMAP

Anotações de rumo, não promessa. Muda sem aviso.

## Regra de ouro

Não inventar vida para o site. Número, status e atividade só entram se vierem de uma checagem real
(widget do Discord, commits do GitHub). O que é demo precisa dizer que é demo.
